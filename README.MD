# What is Project-Leo?

Our current placeholder name for a multiplayer platformer fighting game. The alternate name is “If Rome Never Fell”

Set in the future, in a world where the Roman Empire never fell, the game takes inspiration from Cyberpunk’s aesthetic and Super Smash Bros gameplay and combines them into one.

## ACM Rowdy Creators

This was a game made as apart of UTSA ACM-RowdyCreators. Project created to demonstrate students' ability to create a project within a given timeframe. This project was made in our free time during college. A lot of heart and soul went into the creation of this game, hope you enjoy!
